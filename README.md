# Internship Tracker Dashboard

Our project is a web application that helps students organize and track their internship applications in one place. Users will be able to manage application details, track application statuses, monitor deadlines, and keep track of their progress throughout the internship search process.

## Tech Stack

* **Frontend:** React + JavaScript
* **Backend:** Spring Boot + Java
* **Database:** PostgreSQL (using Supabase)
* **Version Control:** GitHub for collaboration and feature development
* **Deployment:** Vercel + Render + Supabase

Our goal is to build a simple, user-friendly dashboard that makes managing internship applications easier and more organized.
